# Bike Buyers – Excel Data Analysis Project

An end-to-end Excel project covering **data cleaning, pivot tables, charts, and dashboard design**, built on a customer dataset to analyze what drives bike purchases.

## 📊 Overview

This project takes a raw customer dataset (1,000+ records) and walks through a full analysis workflow:

1. **Raw Data** → 2. **Data Cleaning** → 3. **Pivot Tables** → 4. **Charts** → 5. **Interactive Dashboard**

##  Workbook Structure

| Sheet | Purpose |
|---|---|
| `bike_buyers` | Raw dataset — customer demographics, income, occupation, commute distance, and purchase status |
| `Working_Sheet` | Cleaned data — standardized values (e.g. `M`/`S` → Married/Single, `M`/`F` → Male/Female) and a derived **Age Brackets** column |
| `Pivot_Table` | 3 pivot tables summarizing income, commute distance, and age bracket against purchase behavior, with supporting charts |
| `Dashboard` | Consolidated view combining the key charts into a single "Bike Sale Dashboard" |

##  Key Insights

- **~48% of customers purchased a bike** (481 out of 1,000).
- **Proximity matters** — customers living 0–1 miles away had the highest purchase counts; purchases drop off as commute distance increases.
- **Middle-aged customers are the largest buyer segment**, followed by older and then younger age groups.
- **Income varies by gender and purchase decision**, with the pivot table breaking down average income across both dimensions.

##  Skills Demonstrated

- Data cleaning & standardization (recoding values, deriving new columns)
- Pivot tables (multi-dimensional aggregation)
- Chart creation (bar & line charts)
- Dashboard design (combining visuals into a single summary view)

##  Dataset

`bike_buyers` — customer records including:
`ID, Marital Status, Gender, Income, Children, Education, Occupation, Home Owner, Cars, Commute Distance, Region, Age, Purchased Bike`
